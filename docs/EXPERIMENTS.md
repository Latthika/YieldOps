# Experiments and Benchmark Results

The experiment scripts generate their CSV, configuration JSON, and result JSON/Markdown locally under `datasets/synthetic/` and `experiments/`. Those generated files are intentionally excluded from the polished public release; running the scripts recreates them. The numerical summaries below are repeated, provenance-labeled results, not model-performance claims.

## EXP-000: Week-one local HTTP simulator smoke run (historical)

- **Date:** 2026-11-15.
- **Workload:** 20 requests, concurrency 4; deterministic simulator.
- **Outcome:** 20 successes, 0 errors.
- **Measured client HTTP P50/P95/P99:** 1.87/5.14/16.14 ms for that run.
- **Simulated inference P50/P95/P99:** 35/36/36 ms from fixed formulas.
- **Limits:** one small run; no model execution or GPU. See the historical audit details in `docs/PROJECT_AUDIT.md`.

## EXP-M2: In-process API path

- **Configuration:** `experiments/configs/milestone_2_inprocess.json`.
- **Result:** `experiments/results/milestone_2_inprocess_benchmark.json` and `.md`.
- **Reproduce:** `PYTHONPATH=src ./.venv/bin/python scripts/run_inprocess_benchmark.py --requests 100 --repetitions 3`.
- **Host:** Apple M4, 16 GB RAM, macOS 15.6.1, Python 3.12.16.
- **Observed:** each of 3 trials completed 100/100 requests. TestClient in-process throughput was 1,024.5 / 1,093.7 / 1,200.8 requests/s. TestClient P50/P95/P99 ranged from 0.808/0.892/1.141 ms to 0.958/1.086/1.214 ms across trials.
- **Backend field:** simulator P50/P95/P99 were 32/32/32 ms in each trial. These numbers were generated by the simulator formula, not timed model work.
- **Limits:** `TestClient` calls the ASGI app in process; no socket or network path. This is measured application-path overhead, not production capacity or model speed.

A separate Uvicorn socket run was attempted but the local sandbox denied binding to `127.0.0.1:8000` (`operation not permitted`). The HTTP workload runner is unit-tested using HTTPX MockTransport. No network permission was granted to bypass the sandbox.

## EXP-M3: Synthetic workload intelligence baselines

- **Configuration:** `experiments/configs/milestone_3_baselines.json` (seed 42).
- **Result:** `experiments/results/milestone_3_baselines.json` and `.md`.
- **Dataset:** `datasets/synthetic/workload_demand_hourly.csv`, 672 generated hourly rows; first 504 train, final 168 test.
- **Forecast scores:** last-value MAE/RMSE 16.429/19.176 requests; 24-hour seasonal-naive MAE/RMSE 8.381/10.497 requests. On this generated series the seasonal-naive baseline had lower error. This is not evidence on real traffic.
- **Anomaly scores:** both rolling median/MAD and rolling mean + 3 sample standard deviations found all 3 injected synthetic anomalies with 0 false positives (precision/recall 1.000/1.000). This easy, injected test does not establish real monitoring performance.
- **Reproduce:** `PYTHONPATH=src ./.venv/bin/python scripts/run_milestone_experiments.py`.

## General limits

No real inference request was sent to a model runtime. No CUDA or GPU metrics, model quality, cost savings, infrastructure bill, or optimizer improvement has been measured. The cost module is formula-tested with hypothetical rates; no price card is presented as current provider pricing. All reports preserve measured, simulated, and synthetic distinctions.
